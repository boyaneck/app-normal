# app-normal


제목: appnormal
한줄 소개 : 라이브 스트리머가 코파일럿을 이용하여 방송 가능한 라이브 스트리밍 웹사이트
주요 기능 : 지난 방송 데이터를 가지고 AI 와 대화 가능 
            방송 종료 후 후원금액,시청자 수 등과 같은 지표를 직관적으로 확인하고 분석가능
            채팅, 후원 
            라이브 스트리머는 방송 중 생기는 데이터를 AI에게 전달, 유의미한 피드백으로 받아 방송의 질을 높일 수 있음
